# D-001: Adapt the thermo-nuclear rubric into Lens 2, not import it

- **Status**: active
- **Date**: 2026-09-27
- **Decision**: The structure lens (Lens 2) of request-code-review incorporates the maintainability standards of cursor/plugins' `thermo-nuclear-code-quality-review` rubric — code-judo reframing, ~1000-line file boundary, spaghetti-growth, thin-wrapper, type/boundary, canonical-layer, orchestration, and output-discipline rules — rewritten in this plugin's own words inside the reviewer template's "How to review" section, which is Lens 2's body.
- **Rationale**: The rubric's concrete judgments fill the one thin spot in the pipeline (the structure lens was a single abstract paragraph) while the pipeline supplies what the rubric lacks (adversarial verification, severity taxonomy, defect/intent coverage). Rewriting keeps the file's terse register, avoids importing Cursor-specific sections (approval bar, tone phrases), and sidesteps verbatim-copy licensing questions.
- **Rejected alternatives**: Verbatim import of the rubric with attribution — 200+ lines of foreign register, includes sections irrelevant to a lens text. Separate explicit Lens 2 blockquote — leaves the template's default "How to review" section as dead weight and requires a SKILL.md wording change. External reference (link to the rubric) — a prompt template must be self-contained for fresh-context subagents.
- **Supersedes**: none
