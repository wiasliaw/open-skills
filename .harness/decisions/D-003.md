# D-003: Walkthrough template pins per walk in the header only, dropping WOR-31's per-stop SHA

- **Status**: active
- **Date**: 2026-09-30
- **Decision**: `skills/codewalk/templates/walkthrough.md.template` records the commit pin once, in the header (`Commit pin:`), and per-stop records carry only anchor, `file:line`, and the verbatim snapshot — no per-stop `Pinned at:` line, although WOR-31's per-stop content list names a generation-time commit SHA.
- **Rationale**: the pin is walk-level by spec (one HEAD per walk), so within a single walkthrough the per-stop value can never differ from the header — the line was pure duplication with a risk of divergence-by-typo. The user decided the deduplication explicitly on 2026-09-30 after it was surfaced as a pending judgment call from the structural review round.
- **Rejected alternatives**: keeping the per-stop line for literal spec fidelity (rejected by the user: no information content); making the pin per-stop-variable (contradicts the walk-level pin rule in SKILL.md Step 3).
- **Supersedes**: none
